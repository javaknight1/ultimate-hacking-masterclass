# The Complete Ethical Hacking & Cybersecurity Masterclass

A self-contained ethical-hacking course — single HTML file, no server required. Terminal/matrix-green theme, sidebar navigation, progress tracking, and a hands-on **Homework / Lab** at the end of every lesson.

**18 modules · 40 lessons · zero → job-ready operator:**

- 00 Orientation — ethics, law & rules of engagement
- 01 Foundations — security mindset, lab build, Linux
- 02 Kali Linux — what it is, how it works, driving the toolset
- 03 Networking — TCP/IP, packet analysis
- 04 Recon & Scanning — OSINT, nmap
- 05 Web & Vulns — CVEs/CVSS, OWASP Top 10, Burp
- 06 Exploitation — Metasploit, password attacks, privesc
- 07 Pivoting & Tunneling
- 08 Active Directory — fundamentals, enumeration, attacks
- 09 Cloud Security — IAM, misconfigurations
- 10 Binary Exploitation — memory corruption, reverse engineering
- 11 API Security
- 12 Mobile, IoT & Containers — incl. **OT / ICS / SCADA**
- 13 Wireless & Social Engineering
- 14 Scripting & Custom Tooling
- 15 **AI Hacking** — OWASP LLM Top 10, prompt injection, adversarial ML, AI red-teaming (5 lessons)
- 16 Methodology & CTFs
- 17 Defense & Career — blue team, **detection/threat-intel/DFIR**, reporting, certs & roadmap

**Ethics:** every offensive technique is taught for **authorized, legal** practice only — your own lab VMs and deliberately-vulnerable ranges (HackTheBox, TryHackMe, PortSwigger Academy, VulnHub, GOAD, flAWS.cloud, etc.). The course builds the authorization habit from Module 0 and never drops it.

Single self-contained `index.html`. No dependencies, no build step. Deploys to Cloudflare Pages as-is.
